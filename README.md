# kidstube-player

Static GitHub Pages site for two private LG webOS TV apps by Think Define Create LLC
(the "YouTube" app and "Learn & Earn"). Served from the **gh-pages** branch at
<https://think-define-create.github.io/kidstube-player/>. `main` is kept identical by the publish script.

| Path | What |
|---|---|
| `player.html`, `index.html` | The player page. The TV apps load `player.html?v=VIDEO_ID` in a full-screen frame. Being served from a real HTTPS origin avoids YouTube Error 153 (no Referer from a packaged `file://` app). It plays only the one video ID it is given and takes commands only from the embedding app. |
| `config/youtube.json`, `config/learn.json` | **The lists. Edit these** (see [EDITING.md](EDITING.md)). |
| `data/youtube.json`, `data/learn.json` | Generated by `tools/publish.sh`: checked lists plus each channel's resolved videos. Don't edit. |
| `tools/publish.sh` | Pull, validate, resolve channel videos, write `data/`, commit, push to main + gh-pages. |
| `tools/lib.js`, `tools/remote-data.js` | Shared code. The app build scripts copy these into the apps. |
| `tools/channel-id.js` | `node tools/channel-id.js @handle` prints a channel's ID. |

Nothing secret is stored here: no keys, codes or PINs. GitHub Pages sends
`Access-Control-Allow-Origin: *`, so the packaged apps (`file://`) can read the JSON files.
